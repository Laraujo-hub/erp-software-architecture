# Glosario {#section-glossary}

Este glosario define los principales términos utilizados en el dominio del
sistema ERP, especialmente aquellos relacionados con el Módulo de Compras.

| Término | Definición |
|---|---|
| **ERP** | Sistema de planificación de recursos empresariales que centraliza y gestiona diferentes procesos de negocio de una organización. |
| **Módulo de Compras** | Componente del ERP encargado de gestionar las necesidades de adquisición de productos y servicios de la empresa. |
| **Producto** | Artículo que puede ser registrado, solicitado, comprado, recibido y gestionado dentro del sistema. |
| **Proveedor** | Persona o empresa que suministra productos o servicios a la organización. |
| **Solicitud de Compra** | Registro mediante el cual un empleado solicita la adquisición de determinados productos indicando las cantidades requeridas. |
| **Orden de Compra** | Documento generado por el área de compras para formalizar la adquisición de productos a un proveedor. |
| **Recepción de Mercancía** | Proceso mediante el cual se registra la recepción de los productos asociados a una orden de compra y se verifican las cantidades entregadas. |
| **Gestor de Compras** | Usuario responsable de gestionar proveedores, solicitudes y órdenes de compra. |
| **Gestor de Inventario** | Usuario encargado de mantener actualizado el catálogo de productos y gestionar información relacionada con el inventario. |
| **Empleado Solicitante** | Usuario autorizado para registrar solicitudes de compra de acuerdo con las necesidades de la empresa. |
| **Responsable de Recepción** | Usuario encargado de registrar y verificar la mercancía recibida de acuerdo con una orden de compra. |
| **Inventario** | Conjunto de productos disponibles y registrados por la organización, junto con la información necesaria para su control. |
| **Unidad de Medida** | Forma en que se expresa la cantidad de un producto, por ejemplo, unidad, kilogramo, litro o caja. |
| **Estado de Solicitud** | Situación actual de una solicitud de compra dentro del proceso, por ejemplo, pendiente, aprobada o rechazada. |
| **Factura Electrónica** | Documento electrónico que representa una operación de venta o adquisición y que puede ser gestionado mediante un servicio externo de facturación electrónica. |
